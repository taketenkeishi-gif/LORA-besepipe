# LoRA制作ワークベンチ 使い方ガイド

## 0. 起動
1. `start_web.bat` を実行します（デスクトップ版は `start_desktop.bat`）。
2. デスクトップショートカットが必要なら `create_desktop_shortcut.bat` を1回実行します。
3. API状態が `接続OK` になるまで待ちます。
4. 不安定な場合は `stop_all.bat` 実行後に再起動します。

## 1. 外部連携設定（最初に実施）
1. 左メニューの `外部連携設定` を開きます（初回は自動入力済みの値が入ります）。
2. `自動検出` を押します。
3. 必要ならパスを手修正して `保存` を押します。
4. `状態確認` で `Python / kohya / ComfyUI / WD14 / temp_dir / dataset_base_dir` が `OK` か確認します。

## 2. プロジェクト作成
1. `プロジェクト管理` を開きます。
2. プロジェクト名を入力して `作成` を押します。
3. `Character LoRA` か `Style LoRA` を選びます。
4. 一覧から作業対象プロジェクトを選択します。

## 3. データセット作成（Datasetページ）
1. 左メニューの `データセット作成` を開きます。
2. 次のいずれかで候補画像を集めます。
- `収集元URL` + `候補画像取得`
- エクスプローラーから画像をドラッグ&ドロップ
- Web上の画像URLをドラッグ&ドロップ
3. 必要に応じて絞り込みを使います。
- `キーワード`
- `タグ絞り込み`
- `Aspect`（portrait / landscape / square）
- `minW / minH`
4. サムネイルを見ながら使う画像を選択して `取り込み` を押します。
5. `タグ生成` を押して caption を作成します。
6. `繰り返し数` と `フォルダ名` を指定して `4) <repeats>_<title> 作成` を押すと学習用フォルダが作られます（例: `5_subject`）。

補完候補の探索先:
- キャラLoRA: `dataset_base_dir/character`
- スタイルLoRA: `dataset_base_dir/style`

## 4. 学習（Trainingページ）
1. `epochs / rank / alpha / repeats / 保存間隔 / 解像度` を設定します。
2. `出力名 / 学習元Checkpoint / 教師画像フォルダ / 正則化画像フォルダ` を必要に応じて設定します。
3. 軽量プレビュー用 `Positive / Negative` プロンプトを保存します（任意）。
4. `学習開始` を押します。
5. 進捗表示で以下を確認できます。
- 現在epoch
- `done_steps / total_steps`
- 進捗%
- 残り時間目安
6. 停止したい場合:
- すぐ止める: `すぐ停止`
- 区切りで止める: `epoch区切りで停止`
7. 続ける場合は `再開` を押します。

## 5. プレビュー履歴
1. `学習制御` ページ下部の `軽量プレビュー履歴` を確認します。
2. エポックごとに追加される画像を見ながら、品質の変化を追跡します。
3. 良いエポックが見つかったら、そのcheckpointを基準に次調整します。

## 6. 補足
- `1epochあたりstep` はデータ枚数と繰り返し数から自動計算されます。
- `dataset_base_dir` と `temp_dir` は `外部連携設定` で後から変更できます。

## トラブル時
- API状態が `オフライン`:
- `start_web.bat` を再実行
- 直らない場合は `stop_all.bat` -> `start_web.bat`
- パス設定が `NG`:
- 実在するパスか確認
- Pythonは `python.exe` まで含める
- WD14は `tag_images_by_wd14_tagger.py` まで含める
- D&DでURL追加に失敗:
- 直接画像URLでない可能性があります（ページURLの場合）
- その場合はURL欄に入れて `候補画像取得` を実行

## 起動について
- `start_web.bat` は裏で backend / frontend を起動します（複数ターミナルを開かない方式）。
- ログは `.runtime/logs/` に出力されます。
