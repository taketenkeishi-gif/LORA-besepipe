# LoRA制作ワークベンチ 使い方ガイド

## 0. 起動
1. `start_web.bat` を実行します（デスクトップ版は `start_desktop.bat`）。
2. デスクトップショートカットが必要なら `create_desktop_shortcut.bat` を1回実行します。
3. API状態が `接続OK` になるまで待ちます。
4. 不安定な場合は `stop_all.bat` 実行後に再起動します。

## 1. 外部連携設定（最初に実施）
1. 左メニューの `外部連携設定` を開きます（初回は自動入力済みの値が入ります）。
2. `自動検出` を押します。
3. 必要ならパスを手修正して `パスを保存` を押します。
4. `状態確認` で `Python / kohya / ComfyUI / WD14` が `OK` か確認します。
5. `一時保存ディレクトリ` と `データセット補完ベース` も必要に応じて変更します。

## 2. プロジェクト作成
1. `プロジェクト管理` を開きます。
2. プロジェクト名を入力して `プロジェクト作成` を押します。
3. 一覧から作業対象プロジェクトを選択します。

## 3. データセット作成（Datasetページ）
1. `制作ワークフロー` を開きます。
2. `収集元URL` を入力して `候補画像を取得` を押します。
3. サムネイルを見ながら使う画像を選択して `選択画像を取り込み` を押します。
   - キャラLoRA: `dataset_base_dir/character` を優先して候補取得
   - スタイルLoRA: `dataset_base_dir/style` を優先して候補取得
4. `タグを生成` を押して caption を作成します。

## 4. 学習（Trainingページ）
1. `epochs / alpha / repeats` を設定します（stepは自動計算）。
2. `学習開始` を押します。
3. 停止したい場合:
   - すぐ止める: `すぐ停止`
   - 区切りで止める: `epoch区切りで停止`
4. 続ける場合は `再開` を押します。

## 5. プレビューで判断
1. `プレビュー履歴` を確認します。
2. epochごとの差分を見ながら、良いcheckpointを判断します。

## トラブル時
- API状態が `オフライン`:
  - `start_web.bat` を再実行
  - 直らない場合は `stop_all.bat` -> `start_web.bat`

## 起動について
- `start_web.bat` は裏で backend / frontend を起動します（複数ターミナルを開かない方式）。
- ログは `.runtime/logs/` に出力されます。
- パス設定が `NG`:
  - 実在するパスか確認
  - Pythonは `python.exe` まで含める
  - WD14は `tag_images_by_wd14_tagger.py` まで含める
